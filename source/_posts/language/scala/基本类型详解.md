## List

底层实现是单向链表，所以慎用通过index的遍历方式，因为每次都要从头节点开始查。IndexedSeq可以使用

```scala
for (i until nums.lenght) {
  println(nums(i))
}
```

如果需要遍历List，又同时需要获取到index，可以改用迭代或zipWithIndex

```scala
// 迭代


// zipWithIndex
for ((value, index) <- nums.zipWithIndex) {
  ...
}
```
