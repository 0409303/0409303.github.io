## ps

### 查看当前进程

```shell
ps aux
ps -ef
```



### 查看进程父子关系

```shell
# 1. 
ps -o pid,ppid,cmd | grep xxx

# 2. 
ps l | grep xxx

# 3. 保底方式
for pid in $(ps w | grep network_monitor.sh | grep -v grep | awk '{print $1}'); do
    ppid=$(awk '/PPid/ {print $2}' /proc/$pid/status 2>/dev/null)
    echo "PID $pid, PPID $ppid"
done
```
