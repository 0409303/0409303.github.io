## 确认

### 使用的shell类型

```shell
echo $SHELL
```

| 类型 | 登陆时读取的配置文件                                         | 未登录时读取的配置文件 |
| ---- | ------------------------------------------------------------ | ---------------------- |
| Zsh  | ~/.zprofile` 或 `~/.zlogin                                   | ~/.zshrc               |
| Bash | `~/.bash_profile`、`~/.bash_login`、`~/.profile`（按顺序查找第一个） | ~/.bashrc              |
